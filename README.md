# Unix Text Tools

Набор консольных Unix-утилит на языке C с собственной реализацией команд `cat` и `grep`.

Проект посвящён практике:
- работы с файловым вводом/выводом;
- обработки аргументов командной строки;
- работы со строками и текстовыми потоками;
- разработки CLI-приложений на C.

---

# Возможности

## cat

Поддерживаемые флаги:

| Флаг | Описание |
|---|---|
| `-b` | Нумерация непустых строк |
| `-n` | Нумерация всех строк |
| `-s` | Сжатие повторяющихся пустых строк |
| `-e` | Отображение символа `$` в конце строки |
| `-t` | Отображение табуляции как `^I` |

---

## grep

Поддерживаемые флаги:

| Флаг | Описание |
|---|---|
| `-e` | Поиск по шаблону |
| `-i` | Игнорирование регистра |
| `-v` | Инвертированный поиск |
| `-c` | Подсчёт совпадений |
| `-l` | Вывод имён файлов с совпадениями |
| `-n` | Вывод номеров строк |

# Запуск

## cat

### Вывод содержимого файла

```bash
apps/cat/cat tests/test.txt
```

### Нумерация строк

```bash
apps/cat/cat -n tests/test.txt
```

### Сжатие пустых строк

```bash
apps/cat/cat -s tests/test.txt

```

---

## grep

### Поиск строки

```bash
apps/grep/grep hello tests/test.txt
```

### Игнорирование регистра

```bash
apps/grep/grep -i hello tests/test.txt
```

### Вывод номеров строк

```bash
apps/grep/grep -n hello tests/test.txt
```
